# *Enterococcus faecium*

## Usage

The workflow is designed for analysis of *Enterococcus faecium*.

## Supported analysis

The workflow includes the following analyses in addition to species prediction and various methods for assessing the sequencing quality:

- Antibiotic resistance prediction
- Disinfectant resistance
- Prediction of virulence factors
- Plasmid detection
- MLST typing
- cgMLST typing
